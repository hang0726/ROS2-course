# Day 7：GitHub 入门 · 注册 + 建第一个仓库 + 提交课程代码

> 🎯 **今日目标**：注册 GitHub 账号，建你的**第一个仓库（repository）**，把整门 ROS2 课程代码用 Git 提交并推送到 GitHub，养成版本管理习惯。
> 这一步是"保存成果"。命令我给你写好，按顺序做即可。

---

## 一、今天做四件事

### 1. 注册 GitHub（网页，5 分钟）
1. 打开 <https://github.com> → 点 **Sign up**（用邮箱注册，建议用学校邮箱或常用邮箱）。
2. 验证邮箱、设置用户名（username 一旦定下难改，想好再填，比如 `MicckeY`）。
3. 登录后进入首页。

### 2. 建第一个仓库（New Repository）
1. 点右上角 **+ → New repository**。
2. **Repository name**：填 `ros2-course`（或 `my-ros2-course`）。
3. **Description**：填 `我的 ROS2 课程代码（安装/PubSub/Nav2/三节点/GitHub）`。
4. 选 **Public**（公开，免费）或 Private（私有）。
5. ❌ **不要勾** Add a README / .gitignore / license —— 保持仓库**全空**。勾了 README 会让本地首次 `push` 被拒（一键脚本已加自动合并兜底，但空仓库最省事）。
6. 点 **Create repository**。
7. 创建后页面会给出仓库地址，形如 `https://github.com/<你的用户名>/ros2-course.git` —— **记下来**。

### 3. 本机准备 Git + SSH（一次性）
```bash
# git：本机 Windows 已装 2.54，WSL 的 ROS2Course 里也自带 /usr/bin/git，
# 先 git --version 确认；只有提示 command not found 才需要：
# sudo apt install -y git

# ★ 配置身份（必须，换成你的 GitHub 用户名和注册邮箱）
#   没配的话第一次 commit 会报 "Please tell me who you are"
git config --global user.name  "MicckeY"
git config --global user.email "you@example.com"

# 生成 SSH 密钥（一路回车），用于免密推送到 GitHub
ssh-keygen -t ed25519 -C "you@example.com"
# 把公钥内容贴到 GitHub：Settings → SSH and GPG keys → New SSH key
cat ~/.ssh/id_ed25519.pub
```

### 4. 把课程代码推上去
> 用模板脚本最省事：`bash 模板/一键初始化仓库.sh <你的仓库SSH地址>`
> 例如：`bash 模板/一键初始化仓库.sh git@github.com:MicckeY/ros2-course.git`

脚本会自动：`git init` → 加 `.gitignore` → `add` 全部 → `commit` → 连远程 → `push -u`。
（脚本里的仓库根目录默认指向 `D:\ROS2七天速成` 在 WSL 里的路径 `/mnt/d/ROS2七天速成`，按需改。）

## 二、常用 Git 命令（以后天天用）

| 场景 | 命令 |
|---|---|
| 看状态 | `git status` |
| 暂存全部改动 | `git add -A` |
| 提交 | `git commit -m "描述这次改了啥"` |
| 推到 GitHub | `git push` |
| 拉取最新 | `git pull` |
| 看提交历史 | `git log --oneline` |

> 📌 好习惯：每写完一个 Day 就 `git add -A && git commit -m "完成 DayX" && git push`。

## 三、踩了什么坑

- [ ] **坑 1：push 要输密码** —— 用 **SSH 地址**（`git@github.com:...`）而不是 HTTPS，配好 SSH key 后免密。
- [ ] **坑 2：`git init` 建错目录** —— 在课程根目录 `/mnt/d/ROS2七天速成` 里 init，别在子文件夹。
- [ ] **坑 3：把大文件/缓存传上去** —— `build/ install/ log/ __pycache__/` 必须被 `.gitignore` 忽略（模板已含）。
- [ ] **坑 4：commit 前没 add** —— 改了不 `add` 就 `commit`，什么都没存进去。
- [ ] **坑 5：username 没想好** —— GitHub 用户名难改，注册时定好。
- [x] **★ 坑 6：commit 报 "Please tell me who you are"** —— 本机 Windows / WSL 都没有 `.gitconfig`，
  必须先 `git config --global user.name` / `user.email`；一键脚本已加前置检查，没配会直接拦住并打印命令。
- [x] **★ 坑 7：首次 push 被拒（non-fast-forward）** —— 建仓时勾了 `Add a README file`，远程仓库多一个初始提交。
  保持空仓库即可避开；脚本也已加 `fetch + merge --allow-unrelated-histories` 自动兜底。
