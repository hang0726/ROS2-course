## 二、麦轮底盘心智模型（新平台重点）

麦克纳姆轮 = 全向移动，比两驱多一个自由度（能横着走）：

| 指令 | 两驱小车 | 麦轮底盘 |
|---|---|---|
| 前进后退 | `linear.x` | `linear.x` |
| 原地转向 | `angular.z` | `angular.z` |
| **横向平移** | ❌ 做不到 | ✅ `linear.y` |

你 Day12 学过的差速运动学公式不够用了——麦轮要四个轮速一起解算：
```
v_fl = vx - vy - ω(L+W)     # 左前轮
v_fr = vx + vy + ω(L+W)     # 右前轮
v_rl = vx + vy - ω(L+W)     # 左后轮
v_rr = vx - vy + ω(L+W)     # 右后轮
```
（L/W 是轮距半值，具体符号依安装方向。【待材料：实机轮序】）

## 三、今天做什么

### 步骤 1 · 起 ROS2 环境（官方实验 20）
```bash
source /opt/ros/humble/setup.bash
# 【待材料：昇腾机器人 ROS2 工作空间 source 路径】
ros2 node list        # 能看到底盘节点 = 环境通
```

### 步骤 2 · 前进后退控制（官方实验 21）
```bash
# 【待材料：确认底盘订阅的速度话题名，可能是 /cmd_vel 或私有话题】
ros2 topic pub --once /cmd_vel geometry_msgs/msg/Twist \
  "{linear: {x: 0.1}, angular: {z: 0.0}}"
```
🔴 第一次跑**把车架空**——确认方向对、能停，再落地。

### 步骤 3 · 自定义话题（官方实验 22）
用本目录 `mecanum_cmd.py`：订阅 `/cmd_vel`，按上面公式解算四轮速，发布到底盘。
这是你自己的第一个"麦轮运动学节点"——面试能讲清怎么从 vx/vy/ω 解到四轮。

### 步骤 4 · 服务控夹爪（官方实验 23/25）
```bash
# 【待材料：夹爪服务名与消息类型】
ros2 service call /gripper_control <类型> "{open: true}"
```
用本目录 `gripper_client.py`：写一个 service 客户端，控制夹爪开合。
🔑 service 是"一问一答"——适合"开/关夹爪"这种指令，和 topic 的"连续速度"正好分工。

### 步骤 5 · 底盘健康自检
```bash
python3 chassis_health_check.py    # 检查 /cmd_vel /odom /battery 通不通
```
（沿用旧小车线写的通用自检节点，本体无关，直接复用。）
