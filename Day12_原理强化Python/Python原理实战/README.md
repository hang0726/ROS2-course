## 四、核心公式速查（详细推导在答案代码注释里）

**差速运动学**（两轮差速车，轮距 `L`，左右轮线速度 `v_l`/`v_r`）
```
正运动学：v = (v_l + v_r) / 2        ω = (v_r - v_l) / L
逆运动学：v_l = v - ω·L/2            v_r = v + ω·L/2
```

**航迹推演（里程计积分）**，每 `dt` 秒：
```
x += v · cos(yaw) · dt
y += v · sin(yaw) · dt
yaw += ω · dt
```
> 🔑 这就是 `/odom` 的来历：编码器测轮速 → 差速运动学 → 积分。它**会累积误差**，所以才需要 AMCL 用雷达校正——这正好串起你 Day5 学的定位。

**PID 速度闭环**
```
e = 目标 - 实际
u = Kp·e + Ki·∫e·dt + Kd·(e - e_prev)/dt
```
- Kp 管「反应快慢」，Kp 大响应快但易超调
- Ki 管「消除稳态误差」，太大易积分饱和
- Kd 管「抑制震荡」，对噪声敏感
