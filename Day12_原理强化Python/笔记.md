## 二、上午：实验 1 —— 差速运动学 + 里程计

**要搞懂的问题**：`/odom` 到底怎么来的？
```
编码器测左右轮速 → 差速运动学合成 v/ω → 按 dt 积分出 x/y/yaw
```
1. 读 `Python原理实战/README.md` 的公式速查。
2. 跑答案：`python3 Python原理实战/答案/diff_drive_odometry.py`，另开终端发速度，看 x/y/yaw 变化。
3. **自己填练习**：`my_diff_drive_odometry.py` 的 TODO(1)~TODO(41)，对照答案同名编号。
4. ✅ 通关：发速度后位姿持续变、停发后保持不变。

> 🔑 讲给面试听：里程计是积分算的，**会累积漂移**，所以才要 AMCL（Day11）用雷达地图校正——整条链路串起来了。

## 三、下午：实验 2 —— PID 速度闭环

**要搞懂的问题**：Kp/Ki/Kd 各管什么？
```
u = Kp·e + Ki·∫e·dt + Kd·(e-e_prev)/dt
```
1. 跑答案：`python3 Python原理实战/答案/pid_velocity_controller.py`，看 actual 从 0 逼近 target=0.5。
2. 改 `KP/KI/KD` 常量重跑，观察：Kp 大超调、Ki 消稳态误差、Kd 抑震荡。
3. **自己填练习**：`my_pid_velocity_controller.py` 的 TODO(1)~TODO(34)。
4. ✅ 通关：能说出"哪个参数改了会怎样"。
