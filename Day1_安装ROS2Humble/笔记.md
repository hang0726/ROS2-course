## 一、今天学了什么

### 0. 【备查】装 Ubuntu-22.04 发行版（✅ 本机已完成，跳过）

> ✅ 本机已装 Ubuntu 22.04.5 LTS。Windows 端 `wsl -l -v` 能看到 `Ubuntu-22.04`。**此节仅换机/重装时用。**
> 如需新装，在 **Windows 终端（管理员）** 跑：
> ```powershell
> wsl --install -d Ubuntu-22.04
> ```
> 首次启动会让你设**用户名/密码**。装完验证：`lsb_release -a` 应显示 Ubuntu 22.04。

### 1. 路线选择

| 路线                        | 适合谁             | 一句话                                                     |
| ------------------------- | --------------- | ------------------------------------------------------- |
| **WSL2 Ubuntu 22.04（本机在用）** | 本机已装 WSL2     | Windows 里跑 Ubuntu 子系统，直接装 ROS2，和 Windows 文件互通（`/mnt/d`） |
| 虚拟机 VMware / VirtualBox   | 想要"完全隔离的 Linux" | 在 Windows 上跑一个 Ubuntu 22.04 虚拟机，里面装 ROS2                |

> ⚠️ 本机是 Windows 家庭版，**没有 Hyper-V**。要装独立 VM 用 VMware（2024-11 起免费）或 VirtualBox 7.x，并启用 `HypervisorPlatform` 才能和 WSL2 共存。
> 🚫 **红线**：不要执行 `bcdedit /set hypervisorlaunchtype off`，会关掉 WSL2 / Docker。

### 2. 【备查】装 ROS2 Humble（✅ 本机已完成，跳过）

> ✅ 本机 `ros2` 已可用、终端显示 `[ok] ROS2 Humble loaded`。**此节仅换机/重装时用。**
> 一键脚本（自动做：locale → 加 ROS2 apt 源+密钥 → 装 `ros-humble-desktop` + `ros-dev-tools` → 写 `~/.bashrc` → 验证）：
> ```bash
> cd /mnt/d/ROS2七天速成/Day1_安装ROS2Humble/模板
> bash day1_install_ros2.sh
> ```
> `ros-humble-desktop` 约 1~2 GB，apt 下载要耐心等。装完重开终端（或 `source ~/.bashrc`）即可用 `ros2`。

### 3. 验证安装（👈 今天真正要做的一步）

```bash
# 终端1：起一个 C++ 发布者（每秒发 "hello world"）
ros2 run demo_nodes_cpp talker

# 终端2：起一个 Python 订阅者，应该持续收到消息
ros2 run demo_nodes_py listener

# 另开终端看系统里有没有话题
ros2 topic list          # 应看到 /chatter
ros2 node list           # 应看到 /talker /listener
```

> 看到 `ros2 topic list` 出 `/chatter`、订阅者打印消息，Day1 就算通关。

### 4.（可选）一键自检

就绪后想一次性核对环境，跑课程自带检查脚本：

```bash
bash /mnt/d/ROS2七天速成/Day1_安装ROS2Humble/模板/env_check.sh
```

它会逐项打印：Ubuntu 版本 / `ROS_DISTRO` / `ros2` 命令 / 关键包 / locale / `.bashrc` 是否自动 source。

## 二、踩了什么坑

- [x] **坑 0：本机没装发行版 —— 已排除。** 实测本机已有 `Ubuntu 22.04.5 LTS` + `ROS2 Humble`（2026-11-10 现场确认），跳过装机，直接验证。
- [ ] **坑 1：忘了 `source`** —— 没 source 就 `ros2 ...` 会 `command not found`；没 source 就 `import rclpy` 会 `ModuleNotFoundError`。写进 `~/.bashrc` 最省心（装 ROS2 时已自动写）。
- [ ] **坑 2：locale 没设** —— 没 `en_US.UTF-8` 时 ROS2 启动报 locale 警告，严重时会直接退出。
- [ ] **坑 3：网络/换源** —— `packages.ros.org` 有时慢，可临时用国内镜像源（清华/中科大）替换源地址；但**只换 apt 源，ROS2 密钥和源列表写法不变**。
- [ ] **坑 4：WSL 忘 cd** —— 在 WSL 里跑课程代码前先 `cd /mnt/d/ROS2七天速成/DayX`，否则找不到文件。
- [ ] **坑 5：虚拟机路线选错** —— 本机无 Hyper-V，**别用 Hyper-V 虚拟机**；用 VMware/VirtualBox，且别动 `bcdedit`。
