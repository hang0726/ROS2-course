## 一、今天学了什么

### 1. 本课程包结构（已为你建好，直接 build）
```
Day3_工程化ColconLaunch/                # ← 这就是 colcon 工作空间根
├── src/
│   └── my_robot_course/                # 你的包（包名也叫 my_robot_course）
│       ├── __init__.py                 # 包标识（ament_python 必须）
│       ├── talker.py                   # 发布者（ros2 run ... talker）
│       ├── listener.py                 # 订阅者（ros2 run ... listener）
│       ├── service_param.py            # 加法服务 + 参数示例
│       ├── launch/
│       │   └── pubsub.launch.py        # 一键起 talker+listener
│       ├── package.xml                 # 包清单（依赖声明）
│       └── setup.py                    # 构建脚本 + 节点入口注册
└── install/  build/  log/              # colcon build 后自动生成（现在还没有）
```
> `模板/` 文件夹是**逐文件讲解参考**（内容与 `src/my_robot_course/` 一致）；真正编译用的是 `src/my_robot_course/`。

### 2. 编译与运行
```bash
source /opt/ros/humble/setup.bash
cd /mnt/d/具身智能求职培训/Day3_工程化ColconLaunch   # 课程包根目录（里面有 src/）
colcon build --packages-select my_robot_course    # 只编这个包
source install/setup.bash                        # 关键！让系统找到你的包
ros2 run my_robot_course talker                   # 跑发布者
ros2 run my_robot_course listener                 # 跑订阅者（另开终端）
ros2 launch my_robot_course pubsub.launch.py      # 一键起 talker+listener
```
> ⚠️ 每次新开终端都要 `source install/setup.bash`（或写进 `~/.bashrc` 末尾）。
> 在 `/mnt/d`（Windows 盘）上 `colcon build` 会偏慢，属正常——等它跑完即可。

### 3. launch 文件：一条命令起多个节点
`launch/pubsub.launch.py` 里用 `Node()` 把 talker、listener 一起拉起（见 `src/` 或 `模板/`）。launch 还能传参、设 `ROS_DOMAIN_ID`、嵌套其它 launch。

### 4. 服务（Service）—— 一问一答
和话题不同，服务是**同步问答**：客户端发请求，服务端算完返回。适合"发指令等结果"（如清错、标零）。
```python
# 服务端
self.create_service(AddTwoInts, '/add_two_ints', self.cb)
# 客户端
self.cli = self.create_client(AddTwoInts, '/add_two_ints')
```

### 5. 参数（Parameter）—— 节点自己的配置
可运行时改，不重启节点：
```python
self.declare_parameter('speed', 0.5)
speed = self.get_parameter('speed').value
# 运行时改：ros2 param set /param_node speed 1.5
```

## 二、踩了什么坑

- [ ] **坑 1：忘了 `source install/setup.bash`** —— `ros2 run` 报找不到包；新终端必 source。
- [ ] **坑 2：setup.py 的 entry_points 写错** —— `console_scripts` 里 `名字=包.模块:函数`，模块路径拼错就 `ModuleNotFoundError`。
- [ ] **坑 3：package.xml 漏写依赖** —— 用了 `std_msgs`/`example_interfaces` 却没在 `<exec_depend>` 声明，`colcon build` 或运行时缺包。
- [ ] **坑 4：launch 文件名不是 `*.launch.py`** —— `ros2 launch` 找不到；后缀必须 `.launch.py`。
- [ ] **坑 5：服务客户端没等服务端** —— 直接 `call_async` 可能服务端还没起；用 `wait_for_service()` 先等。
- [ ] **坑 6：Python 模块/文件名用了中文** —— ROS2 包里模块名必须是 ASCII（如 `service_param.py`）；中文名会导致 import / entry_points 找不到。课程已统一改成英文文件名。
