# 自动搬运系统全链路（Day13 · 综合收官）

> 🎯 把 Day8-12 所有能力串成一条"语音 → 搬运"的端到端系统图，这是你简历和 demo 视频的核心。

---

## 一、完整链路（每个环节对应你学过的天）

```
用户说"去拿红色方块并放到蓝色区"
   │
   ├─① 麦克风采集        [Day13 实验2]
   ├─② ASR 语音转文字    [Day13 实验3]        → "去拿红色方块并放到蓝色区"
   ├─③ NLP 意图解析      [Day13 实验4]        → {action:pick&place, target:红, dest:蓝}
   │
   ├─④ 任务规划          [Day11]              → 子任务序列：导航→识别→抓取→导航→放置
   ├─⑤ 导航到目标区      [Day11 路点导航]     → Nav2 走到红色方块附近
   ├─⑥ 目标检测          [Day12 昇腾AI部署]   → AscendCL 推理出红方块框中心(u,v)
   ├─⑦ 像素→三维坐标     [Day10内参+Day11手眼] → 机械臂基座坐标(x,y,z)
   ├─⑧ MoveIt 抓取       [Day11/12]           → 规划轨迹 + 夹爪 service 闭合
   ├─⑨ 导航到蓝色区      [Day11]              → Nav2 走到目标
   └─⑩ 放置              [Day12]              → MoveIt 松开 + 夹爪张开
```

🔑 这一条链覆盖：**语音 + NLP + 导航 + AI视觉 + 手眼标定 + 机械臂**——具身智能岗位要的全在里面。

---

## 二、节点与话题清单（照着搭）

| 环节 | 节点/模块 | 话题/服务 |
|---|---|---|
| 语音 | asr_node（厂商SDK）【待材料】 | `/speech_text` (String) |
| 意图 | nlp_node | `/task_command` (自定义) |
| 调度 | task_manager | 发布导航目标 + 触发抓取 |
| 导航 | Nav2（已有） | `/navigate_to_pose` action |
| 检测 | ascendcl_detector（Day12 C++） | `/detections` (Detection2DArray) |
| 抓取 | arm_controller | MoveIt action + `/gripper_control` service |

---

## 三、调试策略（★ 别整体调）

🔴 **分模块逐个测，全通了再串**：
1. 语音单独测：说话 → `/speech_text` 有正确文字
2. NLP 单独测：喂文字 → `/task_command` 结构对
3. 导航单独测：给点 → 车走到
4. 检测单独测：给图 → 框对
5. 抓取单独测：给坐标 → 抓起
6. 最后串起来跑全流程

## 四、demo 视频脚本（30-60 秒）

1. 开头字幕：系统架构图（贴这张链路图）
2. 说话 → 屏幕显示识别出的文字和意图
3. 车导航到目标（画面跟拍）
4. 检测结果可视化（框出红方块）
5. 机械臂抓取 → 搬运 → 放下
6. 结尾字幕：benchmark 数字（识别率/成功率/耗时）
