## 一、今天为什么重要

前几天是"单项能力"，今天是**综合系统**：
```
语音指令 → ASR转文字 → NLP理解意图 → 任务规划 → 导航 → 视觉识别 → 抓取 → 搬运
```
这条链走通，你就有了"从自然语言到机器人动作"的端到端经验——
这是具身智能最前沿的方向（VLA/大模型控机器人），也是你求职的终极展示。

## 二、语音交互三层（官方实验 2-5）

| 层 | 干什么 | 对应实验 |
|---|---|---|
| **采集** | 麦克风采集声音，降噪/端点检测 | 2 |
| **ASR** | 语音转文字（Speech → Text） | 3 |
| **NLP** | 理解意图（"去拿红色方块" → 目标=红色方块，动作=拿） | 4 |
| **命令执行** | 意图 → ROS2 任务 | 5 |

🔑 面试话术："我做了**语音→语义→机器人动作**的跨模态链路"——比"我调了个语音识别 API"高一个层次。

### 步骤 3 · 端到端自动搬运（官方实验 34，★ 综合收官）

## 四、今天踩坑（预置）

- [ ] **语音识别不准** —— 环境噪声大；加降噪 / 换安静环境 / 重新训练唤醒词。
- [ ] **意图解析错** —— 表述和模板对不上；加同义词或改用大模型。
- [ ] **链路某段断** —— 分模块逐个测（语音→文字→意图→导航→抓取），别整体调。
- [ ] **抓取失败率高** —— 回 Day11 手眼标定 / Day12 检测阈值。
- [ ] **作品仓库太空** —— 面试官看的是"架构图 + 数字 + demo"，不是一堆散代码。
