## 二、今天做什么

### 步骤 1 · 硬件自检（先看视频 [0-1]）
- 满电、装好雷达和摄像头；**第一次全程把轮子架空**。
- 记下车的 IP（连同一路由器，看路由器后台或卖家文档）。

### 步骤 2 · SSH 上车
```bash
ssh <用户名>@<车IP>     # 用户名/密码按卖家镜像说明，通常 root 或 ubuntu
```
✅ 通了就先 `ls`、`pwd`、`ros2 --help` 随便看看，确认是带 ROS2 Humble 的 Linux。

### 步骤 3 · 打开网页中控台（看视频 [1-3-1][1-3-2]）
- 中控台分 **ARM / X86 两个架构版本**，你车上（RK3528）选 **ARM 版**。
- 按视频把中控台跑起来，浏览器开 `http://<车IP>:5173`（或 `localhost:5173`）。
- 页面能显示地图区、摇杆、电池/里程计，就算成功。

### 步骤 4 · 认识配置文件（不用改，先看懂）
本目录 `ros_config_示例.json` 是中控台的「遥控器」——所有 ROS2 命令都在这里配：
- `tasks.startup` → 起 Foxglove Bridge（网页靠它连 ROS2，端口 8765）
- `tasks.mapping` → 建图命令（Day10 用）
- `tasks.navigation` → 导航命令（Day11 用）
- `topics` → 话题名映射（Day9 会用到）

> 💡 **今天不要求改任何配置**。能打开页面、知道 `ros_config.json` 是干嘛的就过关。

## 三、今天踩坑（预留）

- [ ] **SSH 连不上** —— 先 `ping <车IP>` 通了再连；确认同一 WiFi。
- [ ] **网页打不开** —— 确认中控台服务起了（`start_console.sh`）；端口 5173 没被占。
- [ ] **页面连不上 ROS2（不显示"已连接"）** —— Foxglove Bridge 没起；检查 `tasks.startup`。
- [ ] **买了 X86 版跑不动** —— RK3528 是 ARM，必须选 ARM 版中控台。
