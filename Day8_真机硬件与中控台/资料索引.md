### chuyun_ws 工作空间有哪些包（对应你 Day3 学的 Colcon）

| 包 | 作用 |
|---|---|
| `chuyun_bringup` | 底盘节点、里程计、TF 处理及启动文件 |
| `chuyun_camera` | HTTP/MJPEG 摄像头流发布 |
| `chuyun_cartographer` | Cartographer 建图配置 |
| `chuyun_description` | URDF / 模型 / RViz 资源 |
| `chuyun_navigation2` | 轻量定位导航 + Nav2 配置 + 地图 |
| `chuyun_opencv` | 颜色/形状/模板匹配示例 |
| `chuyun_wifi_config` | 通过 ROS2 话题配 WiFi（调 nmcli） |
| `micro-ROS-Agent` / `micro_ros_msgs` | micro-ROS 代理（底层单片机用） |
| `slam_gmapping` / `openslam_gmapping` | gmapping 的 ROS2 封装（真机建图默认） |
| `ros2_astra_camera` | Astra 深度相机驱动 |

构建命令（和 Day3 完全一样）：
```bash
mkdir -p ~/chuyun_ws
git clone https://github.com/czu963889306-dev/chuyun_ws.git ~/chuyun_ws/src
cd ~/chuyun_ws && colcon build && source install/setup.bash
# 只编译单个包：colcon build --packages-select chuyun_description
```

## 二、 ros2_web 中控台（面试作品的关键工具）

这是最值得你单独做一个仓库的东西——**网页上就能建图、导航、存图**，面试官一看就懂。

**技术栈**：Vue 3 + Vite 前端 / Node.js Express 后端 / Foxglove WebSocket v1 / ROS2
**环境**：Ubuntu 22.04（WSL 兼容）+ ROS2 Humble + Node.js v18+ + `foxglove_bridge`

**启动**：
```bash
cd ros2_web            # 分 ARM / X86 两个架构版本，按你的主控选
bash start_console.sh
# 浏览器打开 http://localhost:5173
```

**核心功能**：
- 实时 SLAM 栅格地图显示
- 网页摇杆远程控制
- 电池电压 + 里程计实时监测
- 可视化建图控制（开始 / 停止）
- 网页端输入名字保存地图
- 自动连接 `ws://<页面主机>:8765`（Foxglove Bridge）

**全部配置集中在 `ros_config.json`（以它为准，README 只是说明）**：
- `tasks.startup` — 后台启动 Foxglove Bridge
- `tasks.mapping` — 建图命令，默认 `slam_gmapping`
- `tasks.navigation` — 导航命令，新版默认 Lite：`ros2 launch chuyun_navigation2 lite_navigation.launch.py`（可切 Nav2）
- `save_map.save_dir` / `maps_dir` — 地图目录，默认 `/root/chuyun_ws/src/chuyun_navigation2/maps`
- `camera.stream_url` — 摄像头流地址
- `topics` — 话题名映射（`cmd_vel` / `battery` / `map` / `costmap` / `scan` / `tf` / `odom` / `plan` / `goal_pose` / `initial_pose` / `imu` 等）

> 💡 **面试价值**：把 `topics` 改成你自己的话题、录一段网页中控台操作的视频，比纯终端 demo 直观得多。

## 四、怎么把这份资料变成面试作品

1. **复现视频**：跑通「网页中控台 → 建图 → 导航」，录 30 秒。
2. **benchmark 表**：同一套参数在 Gazebo 仿真 vs 真车各跑 5 次，记录到达成功率 / 定位误差 / 耗时。
3. **开源仓库**：把你的配置文件 + 踩坑记录 + demo 推到 GitHub（用 Day7 学的那套）。
4. **面试话术**：不要说"我买了个玩具车"，要说"我把 Nav2 建图导航链路从仿真迁移到 RK3528 真机，做了 Sim2Real 误差对比"。

> 🔴 红线：卖家声明"未经允许禁止商用，仅供学习交流研究"——你的作品仓库要注明学习用途，别拿去商业分发。
