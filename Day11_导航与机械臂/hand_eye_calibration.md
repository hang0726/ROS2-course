# 手眼标定 AX=XB 讲透（Day11 · 官方实验重点）

> 🎯 这份文档讲清"手眼标定到底在求什么、怎么做"，等学校材料到了照着操作即可。
> 这是 Day12 视觉引导抓取的数学地基，也是岗位 JD 明写的难点（"手眼标定、相机与机械臂坐标对齐"）。

---

## 一、为什么必须标定

相机看到的是**像素坐标 (u,v)** + 深度 **d**；机械臂要的是**三维世界坐标 (x,y,z)**。
两者之间差一个"变换矩阵 X"——手眼标定就是**求这个 X**。没有它，检测到的"红色方块在图像中间"
没法变成"机械臂往哪个三维位置伸手"。

---

## 二、两种安装方式（先搞清楚你是哪种）

| 类型 | 相机装哪 | 求的 X | 方程 |
|---|---|---|---|
| **Eye-in-Hand**（眼在手上） | 相机固定在机械臂末端 | 相机 ↔ 末端执行器 | AX = XB |
| **Eye-to-Hand**（眼在外面） | 相机固定在外部（如架子） | 相机 ↔ 机械臂基座 | AX = XB |

- A = 相机两次姿态的相对运动（从相机标定板拍出来的）
- B = 机械臂两次姿态的相对运动（从机器人读出来的）
- X = 要求的固定变换（相机与臂的关系，不随运动变）

🔴 你手上这台 3D 相机装哪：【待材料：确认是 Eye-in-Hand 还是 Eye-to-Hand】

---

## 三、AX=XB 怎么解（知道原理就够，实际操作用工具）

直觉版：**让机械臂带着相机（或相机看着臂）变换姿态 N 次，每次都记录 A 和 B，
解一个最小二乘，算出让所有方程最成立的 X。**

实际操作（用 ROS2 生态工具）：
```bash
# 用 ROS2 的 handeye 标定包（如 hand_eye_calibration / easy_handeye2）
# 【待材料：学校提供的标定脚本 / 标定板尺寸 / 相机内参】
ros2 launch easy_handeye2 eye_in_hand_calibration.launch.py
# 流程：移动机械臂到不同姿态 → 每姿态检测标定板 → 自动累积 → 求解 → 输出 X
```

标定板：常用 ArUco / 棋盘格，角点检测用 Day10 的 OpenCV 特征提取。

---

## 四、验证标得好不好

标定完，把标定板放一个已知位置：
1. 相机检测 → 用 X 换算 → 得到机械臂坐标系下的预测位置
2. 让机械臂真的伸到那 → 看误差
✅ 误差 < 1cm（教学场景）算合格；大了就重新采更多姿态（15-20 组以上）。
