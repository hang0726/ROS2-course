## 四、按视频设计的补充路线（建议周末做，不动 Day1–7）

> 你已经通关 Day1–7，不用回头重看基础。按下面顺序补「视频有、你没有」的部分即可。

### 第一步：真机主线（进阶版 11 集，按顺序）
1. 看 [0-1] 硬件介绍 + [1-1] 安装 → 对照你的 `笔记.md` 阶段 0
2. 车上跑 `模板/Day8_真机环境自检.sh`（本目录现成）
3. 看 [1-3-1/2] 中控台进入 → 用 `模板/ros_config_示例.json` 连网页中控台
4. 看 [1-4] 地图构建 → 走 `笔记.md` 阶段 3（这次走遍全屋）
5. 看 [2-2] CLI 工具 → 你已经会，跳过或快进

### 第二步：补 C++ 缺口（🔴 最高优先）
- 看进阶版 [2-3] C++ 话题通讯实战（13 min）
- 做本目录 `模板/C++话题通讯/` 的标准范本 + 挖空练习（和 Day2 Python 版一一对应）
- 产出：`colcon build` 能过的 C++ package → 这就是 GitHub 作品集里缺的 C++ 证据

### 第三步：补原理（面试高频，图传版）—— 用 Python 落地（✅ 当前主攻）
- [1-15] 里程计（29 min）+ [1-16] 差速运动学（18 min）→ 能讲清 `/odom` 怎么来的、左右轮速度怎么算
  → **已写成节点**：`模板/Python原理实战/答案/diff_drive_odometry.py`（自己做一遍积分，边跑边看数字）
- [1-17] PID 服务通讯 → 能讲清电机闭环
  → **已写成节点**：`模板/Python原理实战/答案/pid_velocity_controller.py`（PID + 一阶惯性仿真，调参看效果）
- 上面两个都有全注释挖空练习，按 TODO 编号填一遍，比光看视频记得牢。
- [1-11] URDF/TF → 能讲清机器人各坐标系关系（暂无节点，看视频即可）

> 说明：C++ 那套（`模板/C++话题通讯/`）先放着，按用户要求「先用 Python 写」。

### 第四步：串成面试作品
- 用 `模板/Day8_benchmark采样.py` 采数据 → 填 `benchmark记录表.md`
- 用 `README_面试作品模板.md` 建 GitHub 仓库
- 话术见 `资料索引.md` 第四节
