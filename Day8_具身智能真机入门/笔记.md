## 二、六阶段上车流程

> 约定：下面 `<车IP>` 换成小车的实际 IP（连同一个路由器后，卖家文档或路由器后台能查到）。
> SSH 上车的命令：`ssh <用户名>@<车IP>`（用户名/密码按卖家镜像说明，通常是 `root` 或 `ubuntu`）。

### 阶段 0 · 硬件自检（5 分钟）
```bash
# 在车上：满电、装好雷达和摄像头、四个轮子架空
ls /dev/tty*                 # 看雷达/串口设备
ros2 --help                  # 确认 ROS2 Humble 在
echo $ROS_DOMAIN_ID          # 确认和你的 PC 不冲突
```
⚠️ **第一次跑务必把车架空**，防止它突然冲出去撞东西。

### 阶段 1 · 通底盘（对应 Day2）
```bash
ros2 topic list              # 应看到 /cmd_vel /odom /scan /battery
ros2 topic echo /odom        # 手动转轮子，看数值变化
ros2 topic pub --once /cmd_vel geometry_msgs/msg/Twist \
  "{linear: {x: 0.1}, angular: {z: 0.0}}"
```
车动 + odom 变 = 底盘通了。

### 阶段 2 · 检查 TF 树（对应 Day4 前置）
```bash
ros2 run tf2_tools view_frames    # 生成 frames.pdf
```
确认 `map → odom → base_link → laser_frame` 齐全，缺哪个补哪个静态变换。

### 阶段 3 · 真机建图（对应 Day4）
```bash
# 用卖家的 xuegecar_navigation2 / ros2_web 中控台，或手动：
ros2 launch slam_gmapping slam_gmapping.launch.py    # 或 slam_toolbox
# 遥控走完整间屋子（不是只走一小圈！）
ros2 run nav2_map_server map_saver_cli -f ~/maps/my_room
```
⚠️ **别重复你 Day4 的坑**：那次只建了小车附近一小片，地图大部分是 unknown。这次要**走遍每个角落**。

### 阶段 4 · 真机导航（对应 Day5）
```bash
ros2 launch xuegecar_navigation2 navigation2.launch.py
# RViz 里：2D Pose Estimate 给初始位姿 → Nav2 Goal 发目标
```
✅ 你 Day5 学的 `Nav2 Goal`（不是"2D Goal Pose"）在这里原样复用。

### 阶段 5 · 跑你自己写的三个节点（对应 Day6）
```bash
# 你的代码不用改，直接拷到车上跑：
python3 send_nav_goal.py 0.5 0.0 0.0
python3 odom_subscriber.py
python3 velocity_commander.py
```
⚠️ 节点③和 Nav2 都在发 `/cmd_vel`，**不要同时跑**（Day6 的坑在真机上一样成立）。

### 阶段 6 · 做成面试作品（对应 Day7 + 求职）
| 产出 | 怎么做 |

## 三、踩了什么坑（预留，遇到就勾）

- [ ] **坑 1：SSH 连不上车** —— 确认车和 PC 在同一 WiFi；`ping <车IP>` 通了再 SSH。
- [ ] **坑 2：`/cmd_vel` 发了车不动** —— 先架空轮子；检查 `/odom` 是否变化；确认没被 Nav2 占用。
- [ ] **坑 3：建图地图全是 unknown** —— 你 Day4 的坑，这次要走遍整个房间再存图。
- [ ] **坑 4：TF 断链** —— `view_frames` 看哪一段缺，补静态变换或启动 `robot_state_publisher`。
- [ ] **坑 5：真机目标点被拒** —— 和 Day5 一样，先给 AMCL 初始位姿；目标别越出地图边界。
- [ ] **坑 6：`ROS_DOMAIN_ID` 冲突** —— 车和你 WSL2 里其他 ROS2 用不同 domain，避免话题串台。
- [ ] **坑 7：Windows git 换行符** —— 你 Day7 已加 `.gitattributes` 锁 LF，新仓库记得也带上。
- [ ] **坑 8：卖家声明非商用** —— 作品仓库注明"学习交流用途"，别商业分发。
