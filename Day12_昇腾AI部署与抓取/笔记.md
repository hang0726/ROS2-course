## 二、完整链路（今天要亲手走一遍）

```
① MindSpore 训练模型（PC/云）        → .ckpt 权重
② 导出 AIR / ONNX                    → .air / .onnx
③ ATC 转换（关键！soc_version=Ascend310B） → .om
④ AscendCL C++ 加载 .om 推理          → 检测结果（类别+框/坐标）
⑤ 结果发 ROS2 话题                    → /detections
⑥ 像素→世界坐标（Day11 手眼标定）     → 抓取点 (x,y,z)
⑦ MoveIt 规划 + 夹爪 service          → 抓起物体
```

🔑 每一步对应一个实验：①=18 ③=19 ⑥=Day11 ⑦=32/33。**这就是你的项目流水线。**

## 三、今天做什么

### 步骤 1 · 训练 / 拿模型（官方实验 18）
【待材料：学校提供训练脚本或预训练模型】
用 MindSpore 训练一个分类/检测模型（或从 ModelZoo 拿现成的），导出 ONNX/AIR。

### 步骤 2 · ATC 转换（官方实验 19，★ 最容易踩坑）
```bash
atc --model=model.onnx --framework=5 --output=model_ascend \
    --soc_version=Ascend310B --input_shape="input:1,3,224,224"
```
🔴 三个必对：`soc_version=Ascend310B`、`framework=5`(ONNX)、`input_shape` 和训练时一致。
错一个 → 转出的 .om 车上加载失败。

### 步骤 3 · AscendCL C++ 推理（★ 补 C++ 缺口）
用昇腾官方开源样例库 `gitee.com/ascend/samples` 的 ResNet50 分类样例改：
```bash
git clone https://gitee.com/ascend/samples.git
# cplusplus/level2_simple_inference/1_classification/resnet50_imagenet_classification
# 改成加载你的 .om，输出检测结果
```
本目录 `ascendcl_inference_readme.md` 讲清 AscendCL 推理的 5 步（aclInit→加载模型→准备输入输出→推理→释放）。

### 步骤 4 · 检测结果发 ROS2 话题
把 C++ 推理结果包装成 ROS2 节点发布（本目录 `detection_to_ros2.md` 给框架）。
消息可用 `vision_msgs/Detection2DArray`（标准）或自定义。

### 步骤 5 · 视觉引导抓取（官方实验 32/33，★ 收官）
```
检测结果(像素框中心 u,v) + 深度 d → 相机坐标 → (手眼变换) → 机械臂基座坐标 → MoveIt 抓取
```
🔴 6轴臂力量大：抓之前确认工作区无人、急停在手、低速试。

## 四、今天踩坑（预置）

- [ ] **ATC 转换失败** —— soc_version 写错 / framework 编号错 / input_shape 不匹配。
- [ ] **AscendCL 加载 .om 失败** —— 环境变量没 source；CANN 版本和 ATC 转换时不一致。
- [ ] **推理结果全错** —— 预处理（归一化/通道顺序 BGR/RGB）和训练时不一致。
- [ ] **抓取位置偏** —— 手眼标定没做或误差大（回 Day11）；深度值单位错（mm vs m）。
- [ ] **机械臂撞到东西** —— 工作空间没清空；低速 + 急停。
