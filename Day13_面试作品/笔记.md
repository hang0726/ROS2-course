# Day 13：面试作品收官 —— 把六天真机经历变成作品集

> 🎯 **今日目标**：把 Day8–12 的经历打包成面试能展示的三件套：
> **demo 视频 + benchmark 对比表 + GitHub 仓库**。
> 前面五天学技术，今天把技术变成**可验证、可展示的成果**——这是求职培训的收官。

> ⏱️ 不用看新视频；回顾进阶版 `[2-3]` 之后的作品思路 + 你自己的实跑记录。

## 一、面试三件套（缺一不可）

| 产出 | 怎么做 | 本目录现成材料 |
|---|---|---|
| ① demo 视频 | 用 ros2_web 网页中控台录 30 秒：建图→导航→车走到目标 | —（你自己录） |
| ② benchmark 表 | 同目标点，仿真 vs 真机各跑 5 次，填误差/耗时 | `../Day12_原理强化Python/benchmark记录表.md` |
| ③ GitHub 仓库 | 配置 + README + 踩坑 + 视频链接，`git push` | `README_面试作品模板.md` + `视频课程对照与学习路线.md` |

> 💡 没有视频的作品集说服力减半。**先录再写**。

## 二、今天做什么

### 步骤 1 · 录 demo 视频（30 秒）
- 用 Day8 的网页中控台，录：点建图→（快进）→点导航→车走到目标。
- 或终端录屏也行，但要能看清话题名、位姿数字在变。
- 传到 B 站/图床，拿链接。

### 步骤 2 · 整理 benchmark 对比表
- 把 Day12 采的数据填进 `benchmark记录表.md`（仿真 5 次 + 真机 5 次）。
- 算平均误差/成功率/耗时，写一句结论：**真机比仿真差多少、为什么**（里程计漂移/摩擦/雷达噪声）。

### 步骤 3 · 建 GitHub 作品仓库
```bash
# 新建仓库（Day7 学的那套：不勾 README/gitignore/license，保持空）
# 把 README_面试作品模板.md 复制成新仓库的 README.md，按 [ ] 逐条替换
git init
git add . && git commit -m "Sim2Real 导航作品"
git push -u origin main
```
🔴 记得带 `.gitattributes`（`* text=auto eol=lf`）和 `.gitignore`，你 Day7 的配置直接拷。

### 步骤 4 · 写面试话术（背下来）
不要说"我买了个玩具车"，要说：
> "我把 Nav2 建图导航链路从 Gazebo 仿真迁移到 RK3528 真机，自己实现了里程计和差速运动学，
> 用同一套节点在两种环境各跑 5 次做了 Sim2Real 误差对比，代码和 demo 都开源了。"

## 三、今天踩坑

- [ ] **视频太大传不上** —— 压到 30 秒、720p，或只截关键片段。
- [ ] **benchmark 数据是编的** —— 🔴 别编。面试官追问"为什么真机误差大"答不上来比没数据更糟。
- [ ] **仓库只有 README** —— 至少放：配置 + 代码 + 踩坑记录 + 数据 + 视频链接。
- [ ] **卖家声明非商用** —— 仓库注明"学习交流用途"（README 模板里已有声明）。
