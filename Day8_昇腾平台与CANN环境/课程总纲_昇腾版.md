## 一、新平台是什么（和旧小车的本质差异）

**JC-AR-V2 = AI 机器人综合应用开发平台**（官网定位），一台车同时具备"移动 + 机械臂 + AI 算力 + 语音"：

| 维度 | 旧：出云 RK3528 小车 | 新：昇腾 JC-AR-V2 |
|---|---|---|
| 主控算力 | RK3528（A53 CPU，无 NPU） | **昇腾 310B NPU**（端侧 AI 推理） |
| 机械臂 | ❌ | ✅ **6 轴智能机械臂 + MoveIt** |
| 视觉 | USB 摄像头 | ✅ **3D 视觉摄像头**（无标记 3D 视觉引导） |
| 语音 | ❌ | ✅ 无线麦克风 + ASR/NLP/语音命令 |
| 底盘 | 两驱/麦轮 | ✅ 麦克纳姆轮 |
| 雷达/里程计 | 有 | ✅ 有 |
| AI 框架 | 无 | **CANN + MindSpore + ATC 模型转换 + 大模型轻量化部署** |
| 场景 | 建图导航 | 智能仓储 / 服务机器人 / 工业检测 |

🔑 **一句话**：旧小车只能"跑 ROS2 应用"，新车能"在车上跑 AI 推理 + 机械臂抓取"——你之前缺的机械臂、手眼标定、AI 部署、大模型，**这台车全有了**。

## 五、昇腾 AI 栈心智模型（面试会考）

```
┌─────────────────────────────────────────────┐
│  训练侧（PC / 云端，昇腾910B 或 GPU）        │
│  MindSpore / PyTorch → 训练出模型            │
└──────────────────┬──────────────────────────┘
                   │ 导出 ONNX / AIR
                   ▼
┌─────────────────────────────────────────────┐
│  转换：ATC 工具（CANN 自带）                 │
│  ONNX/AIR → .om（昇腾离线模型）              │
│  ★ soc_version 必须写 Ascend310B             │
└──────────────────┬──────────────────────────┘
                   │ .om 模型
                   ▼
┌─────────────────────────────────────────────┐
│  推理侧（车上昇腾310B）                      │
│  AscendCL (C/C++ API) 加载 .om → 推理        │
│  → 检测结果经 ROS2 话题发出 → 机械臂执行      │
└─────────────────────────────────────────────┘
```

三个名字别混：
- **CANN** = 昇腾的底层驱动 + 工具链（类比 NVIDIA 的 CUDA）
- **MindSpore** = 华为 AI 框架（类比 PyTorch）
- **AscendCL** = C/C++ 推理接口（类比 TensorRT 的 C++ API）
