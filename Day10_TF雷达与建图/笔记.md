## 一、建图前先懂两件事（对应视频前两集）

### 1. TF 到底是什么（[1-11]）
TF 是机器人各部件坐标系的"亲子关系表"。建图/导航时必须有：
```
map → odom → base_link → laser_frame
```
- `map→odom`：定位给的（建图时由 SLAM 给）
- `odom→base_link`：里程计给的（Day9 你验证过 `/odom`）
- `base_link→laser_frame`：雷达装在车上的位置（静态变换）

> 你 Day4 查过 TF 树，今天在真车上再看一遍，理解每个 frame 代表什么——面试常问。

### 2. 雷达点云怎么看（[1-12]）
```bash
ros2 topic echo /scan --once       # 看一串 distance 数值
```
RViz2 里加 LaserScan 显示，能看到墙的轮廓。雷达数据是建图的"眼睛"。

## 二、今天做什么

### 步骤 1 · 起雷达 + 确认 TF（Day9 已验证，这里复用）
```bash
ros2 launch <车的雷达launch>       # 具体命令看卖家仓库/视频，或中控台已经起了
ros2 run tf2_tools view_frames
```

### 步骤 2 · 起 Gmapping 建图
```bash
# 方式 A：命令行
ros2 launch slam_gmapping slam_gmapping.launch.py

# 方式 B：网页中控台（推荐，面试演示直观）
# 在 Day8 的 ros2_web 页面点「开始建图」
```
🔴 真机默认 `slam_gmapping`，**不是**你 Day4 学的 `slam_toolbox`——包名不同，原理一样。

### 步骤 3 · 遥控走遍全屋（★ 今天最关键）
- 用 Day9 练熟的键盘控制，**慢慢走遍每个房间、每条走廊**。
- 走的时候让雷达"看到"墙角、门框、障碍物——地图完整度取决于你走到哪。
- ⚠️ **Day4 的坑**：当时只建了小车附近一小片，地图大部分 unknown，导致 Day6 目标越界。这次别重演。

### 步骤 4 · 保存地图
```bash
ros2 run nav2_map_server map_saver_cli -f /root/chuyun_ws/src/chuyun_navigation2/maps/my_room
# 或用中控台「输入地图名 → 保存」按钮
```
✅ 生成 `my_room.pgm` + `my_room.yaml` 两个文件，用 `ls -l` 确认非空。

### 步骤 5 · 看一眼地图质量
用图片查看器打开 `.pgm`，或用 `python3` 看未知区域比例。
✅ 好地图：绝大部分是墙(黑)/空地(白)，unknown(灰) 很少。
